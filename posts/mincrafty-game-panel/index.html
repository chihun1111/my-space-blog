게임 관리 VM에 MinCrafty 패널을 올려 봤다

게임 서버를 관리하려고 MinCrafty 패널을 올렸어요. VM 설정과 대시보드 접속, 자동 시작에서 확인한 내용을 남겼어요.

Chihun2026년 10월 22일수정 2026년 11월 26일5분 읽기

홈서버에서 게임 관리용 VM을 따로 만들고 MinCrafty 패널을 올려 봤다. 이 환경 안에서는 ATM10 마인크래프트 모드팩 서버도 구성해 봤다. 관리 패널은 8443/TCP로 웹 요청을 받았고 /panel/dashboard 경로로 리다이렉트하는 응답이 돌아왔다. 이 글은 그 패널을 올려 둔 VM과 관리 화면의 구성을 다룬다.

게임 관리 환경은 4코어와 80G 디스크로 나눴다

같은 Proxmox 호스트에는 NAS와 데이터 처리 VM도 있지만, 게임 관리 환경에는 별도의 CPU·메모리와 디스크를 할당했다. 2026년 10월 22일 기준으로 남아 있는 설정은 다음과 같다.

항목설정
CPU1소켓 · 4코어, cpu: host
메모리6144MiB, 즉 6GiB
머신 · 펌웨어q35 · OVMF(UEFI)
시스템 디스크scsi0, local-lvm, 80G
SCSI 컨트롤러virtio-scsi-single
네트워크VirtIO NIC → vmbr0, firewall=1

메모리 6GiB는 이 VM 전체에 할당한 양이다. 게임 프로세스의 Java 힙을 6GiB로 지정했다는 뜻은 아니다. 별도의 게임 실행 인자나 월드별 메모리 설정은 이 VM 자원표에서 알 수 없다.

시스템 디스크에는 discard=on,iothread=1,ssd=1이 들어 있다. 게스트의 discard 전달, 별도 I/O 스레드, SSD 장치 표시 옵션을 사용한 구성이다. NAS의 물리 디스크를 직접 붙인 방식과 달리 이 VM의 80G 디스크는 local-lvm의 볼륨이다. Proxmox 디스크 옵션

시스템 디스크에서 부팅하고 브리지로 연결했다

부팅 순서에는 시스템 디스크, CD-ROM, 네트워크가 들어 있다. 그중 첫 번째가 scsi0다.

Text
boot: order=scsi0;ide2;net0
scsihw: virtio-scsi-single
scsi0: local-lvm:<시스템 볼륨>,discard=on,iothread=1,size=80G,ssd=1

VirtIO 네트워크 인터페이스는 vmbr0에 연결돼 있다. 패널은 이 VM 안에서 응답하는 서비스이므로 Proxmox 관리 화면과는 접속 대상이 다르다. VM NIC의 firewall=1도 켜져 있지만, 이 값 하나로 8443 포트의 공개 범위나 허용된 출발지를 설명할 수는 없다. 실제 접근 범위는 적용된 규칙과 접속 경로까지 함께 봐야 한다.

8443 포트에서 대시보드 경로가 돌아왔다

패널을 올렸을 때 남긴 응답 기록은 포트와 웹 서버, 리다이렉트 경로를 보여 준다.

항목당시 응답
웹 패널 포트8443/TCP
웹 서버 식별Tornado
리다이렉트 경로/panel/dashboard

포트가 열려 있다는 기록에 더해, 웹 요청에 패널의 경로를 반환했다는 결과가 남았다. 관리용 웹 애플리케이션이 요청을 받아 응답하는 단계까지 간 것이다.

8443 응답은 관리용 웹 애플리케이션의 동작을 보여 준다. 게임 서버에 사용하는 포트와 역할이 다르므로 이 값을 게임 접속 주소에 그대로 대응시키면 안 된다.

이 패널 안에서 실제로 올려 본 모드팩은 ATM10이다. 관리 도구를 준비한 작업과 모드팩 서버를 구성한 작업을 나눠, 서버팩과 게임 실행 환경에 관한 내용은 MinCrafty 안에 ATM10 모드팩 서버를 올려 봤다에 따로 적었다.

시작 순서 설정은 남아 있지만 지금은 중지 상태다

VM에는 startup: order=80,up=30,down=10이 남아 있다. 시작 순서 값은 NAS의 10, 데이터 처리 VM의 50보다 뒤다. up=30은 다음 VM 시작까지 기다리는 시간이고 down=10은 종료 대기 제한이다. 둘 다 게임 서버가 준비됐다는 신호는 아니다. 시작·종료 설정

반면 이 VM에는 onboot: 1이 설정돼 있지 않다. 시작 순서가 있다는 이유로 호스트를 켤 때 자동으로 시작하는 VM이라고 보면 안 된다.

2026년 10월 22일에는 VM이 중지 상태였다. 위의 8443 포트 응답은 패널을 실행했을 때의 기록이고, 현재는 80G 시스템 디스크와 VM 설정을 남겨 둔 상태다.
