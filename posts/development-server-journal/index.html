요즘 만들고 만지는 것들

말씨, CTF 사이트, 그리고 집에서 돌리는 서버. 그동안 만든 것과 관련 글을 한곳에 모았어요.

Chihun2026년 11월 26일5분 읽기

이 블로그에는 프로젝트를 만들며 배운 것과 홈서버를 만지면서 남긴 메모를 모으고 있어요. 코드를 고친 이야기부터 VM 설정, 게임 서버까지 조금씩 섞여 있어요. 처음 오셨다면 어떤 걸 만들었는지 이 글에서 둘러보셔도 좋을 것 같아요.

코드는 GitHub의 chihun1111에 올리고 있어요. 지금까지 적은 내용은 크게 세 가지예요.

말씨에서 질문과 답변을 다듬었어요

말씨는 HOP Biohealth AI Challenge에서 팀으로 만든 프로젝트예요. 어려움을 겪는 사람 곁의 가족이나 친구가 대화를 준비할 수 있도록, 상황을 묻고 대화문과 행동 가이드를 카드로 보여 줘요.

저는 PostgreSQL과 Gemma를 연결하고, 입력을 남겨 두거나 실패한 요청을 다시 보내는 부분을 손봤어요. 최근에는 다음 질문을 고르는 모델과 최종 카드를 만드는 모델도 나눴어요.

답변을 받고 화면에 보여 주는 사이에도 생각할 게 있었어요. 기다리던 사용자가 내용을 고치면 예전 답변으로 만든 결과는 어떻게 할지, 브라우저를 닫아도 작업을 계속할지 같은 것들이요. 이런 부분을 하나씩 정리한 내용은 말씨를 만들며 질문과 저장을 손본 이야기에 적었어요.

CTF 대회 사이트도 만들었어요

CTF는 문제를 풀어 찾은 정답인 ‘플래그’를 제출하는 방식의 대회예요. 참가자가 문제를 보는 화면과 관리자 페이지를 만들고, 서버를 구성해서 배포하는 것까지 직접 해 봤어요.

화면과 API는 Next.js와 NestJS로 만들고, 데이터는 PostgreSQL에 저장했어요. 참가자마다 다른 플래그를 주고 제출 기록을 남기도록 구성했는데, 점수를 어떻게 보여 줄지도 정해야 했어요. 이미 모든 문제를 푼 사람이 일부 정답만 다시 제출했다고 완료 기록까지 사라지면 안 되니까요.

CTF 사이트를 만들면서 정한 것들에는 이런 제출 처리와 로그인, 관리자 화면, 배포 이야기를 모았어요. 코드는 CTF 저장소에서 볼 수 있어요.

집에서는 서버를 만지고 있어요

홈서버는 Proxmox와 TrueNAS를 중심으로 구성했어요. NAS와 개발용 VM, 데이터 처리 도구, 자동화, 게임 서버를 나눠 올리고 원격 접속도 붙였어요.

설정을 적어 둔 글도 있고, 안 되던 걸 고친 글도 있어요. Discord 봇 여섯 개가 온라인인데 일반 채팅에 답하지 않던 적이 있었어요. 살펴보니 슬래시 명령을 받는 처리는 있는데 일반 메시지를 받는 처리가 빠져 있었고, 결과를 원래 채널로 돌려보내는 부분과 CLI 호출도 고쳤어요. 그 과정은 온라인인 Discord 봇이 답하지 않던 이유에 남겼어요.

웹에서 PC를 켜는 WOL 포털도 만들었어요. 패킷을 보내는 것과 PC가 실제로 준비됐는지는 다른 일이라, Windows 준비 확인과 다음 한 번만 Ubuntu로 부팅하는 작업을 따로 다뤘어요. 자세한 내용은 WOL 포털과 부팅 기록에 있어요.

궁금한 것부터 읽어 주세요

  • AI 대화 프로젝트가 궁금하다면 말씨 이야기
  • 웹 사이트와 서버 배포 쪽이 궁금하다면 CTF 사이트 이야기
  • 홈서버를 어떻게 나눴는지 궁금하다면 제 홈서버 구축 기록
  • 밖에서 서버에 접속하는 방법이 궁금하다면 Tailscale과 SSH 기록

앞으로도 만들어 본 것과 막혔다가 고친 내용을 하나씩 적어 보려고 해요. 홈서버 글에는 당시 설정과 확인한 날짜를 함께 남겼어요. 다음에 다시 만질 때 이 기록이 도움이 되면 좋겠어요.
