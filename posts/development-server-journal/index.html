개발과 홈서버 사이에서 만드는 것들

말씨·CTF 플랫폼·홈서버를 연결해 소개하고, 처음 방문한 독자를 위한 읽기 순서를 정리했습니다.

Chihun2026년 11월 26일6분 읽기

이 블로그에는 내가 만든 서비스와 그 서비스를 받치는 서버의 기록을 함께 남긴다. 웹 화면을 구현하다 보면 데이터 저장과 모델 호출을 다루게 되고, 서비스를 올려 보면 네트워크·스토리지·권한·복구의 문제가 따라온다. 코드와 서버를 오가며 해결한 일을 한곳에서 이어 읽을 수 있도록 정리했다.

GitHub에서는 chihun1111이라는 이름으로 작업한다. 최근 개발 작업은 말씨와 CTF 플랫폼에서, 서버 구성과 운영 기록은 Proxmox·TrueNAS 홈서버 글에서 볼 수 있다.

최근에는 말씨의 대화 흐름과 복구를 다뤘다

말씨는 HOP Biohealth AI Challenge에서 함께 만든 팀 프로젝트다. 어려움을 겪는 사람 곁의 가족이나 친구가 대화와 행동을 준비하도록 돕는다. 나는 PostgreSQL과 Gemma 모델 경로를 연결하고, 입력 보존과 재시도, 후속 대화, 카드 저장 흐름을 개선하는 작업에 참여했다.

최근 변경에서는 질문을 고르는 모델과 최종 카드를 만드는 모델의 역할을 나누었다. 사용자가 답변을 고치는 동안 예전 결과가 도착하거나, 결과를 만드는 서버가 재시작하는 경우도 다뤘다. 화면에 응답을 보여 주는 일과 올바른 버전의 결과를 끝까지 저장하는 일을 함께 생각한 프로젝트다.

말씨 개발 기록: AI의 답변을 끝까지 전달하고 저장하기에서 질문 흐름, 상태 관리, 결과 작업의 실행 권한과 복구를 자세히 적었다. 프로젝트 소스와 내 변경 이력도 함께 볼 수 있다.

CTF 플랫폼에서는 참가와 운영을 함께 만들었다

CTF 플랫폼은 문제를 보여 주고 정답을 받는 화면에서 시작해, 참가자 진행 상황과 제출 내역을 확인하는 관리자 기능, 데이터 보호, 서버 구축과 배포까지 직접 맡은 프로젝트다.

현재 공개 코드에는 Next.js 화면과 NestJS 백엔드, PostgreSQL, Redis, Nginx, Docker 구성이 들어 있다. 참가자가 어떤 문제를 풀었는지 확인하는 과정과 최종 제출을 확정하는 과정, 운영자가 상태를 보는 과정을 구분했다. 각 계층의 성공과 실패를 어떻게 연결할지가 중요한 주제다.

CTF 플랫폼을 만들며 배운 인증·제출·운영의 경계에서는 개인별 플래그, 제출과 기록의 일관성, 관리자 기능과 서비스 배포 구조를 다룬다. 구현은 CTF 플랫폼 저장소에서 확인할 수 있다.

홈서버는 서비스를 직접 올려 보는 환경이다

홈서버는 Proxmox 위에 TrueNAS, 개발 환경, 데이터 처리, 자동화, 게임 서버를 나눈 구성이다. VM마다 CPU·메모리·디스크와 주소를 배정하고, 저장소와 접속 경로를 연결해 왔다.

개발 프로젝트와 이어지는 글부터 읽으려면 다음 순서가 좋다.

  1. 홈서버 구축 기록 — 전체 구성을 네 주제로 정리한 안내.
  2. PostgreSQL과 데이터 처리 VM — 데이터 서비스를 위한 환경 구성.
  3. Tailscale과 SSH 접속 — 원격 경로와 실제 접속 결과.
  4. 온라인인 Discord 봇이 답하지 않던 이유 — 메시지 수신부터 CLI 호출까지 오류를 좁힌 과정.
  5. WOL 포털과 Windows·Ubuntu 부팅 — 전원 제어와 OS 전환을 연결하며 고친 문제.

홈서버 글은 2026년 10월에 확인한 구성과 당시의 응답을 바탕으로 썼다. 소개에 목록이 있다고 해서 모든 서비스가 지금도 정상 운영된다는 뜻은 아니다. 각 글의 날짜와 마지막 확인 상태를 함께 읽으면 어떤 부분을 구현했고 무엇을 더 확인해야 하는지 구분할 수 있다.

앞으로도 문제와 확인 결과를 함께 남기기

이곳에서는 기능 이름이나 기술 목록만 나열하지 않으려고 한다. 어떤 상황에서 문제가 생겼는지, 원인을 어떻게 좁혔는지, 무엇을 바꾸고 어디까지 확인했는지를 함께 적는다.

예를 들어 VM이 켜지는 것, SSH로 접속되는 것, 앱이 응답하는 것, 결과가 데이터베이스에 저장되는 것은 서로 다른 확인 단계다. AI 서비스에서는 모델이 문장을 반환하는 것에 더해, 그 문장이 현재 답변에서 나온 결과인지와 저장이 끝났는지도 확인해야 한다.

다음 작업에서는 말씨의 실제 모델 검증 범위와 질문·생성·저장의 각 단계를 더 구체적으로 기록하고 싶다. 홈서버에서도 이미 확인한 설정과 접속이 막혀 남겨 둔 문제를 이어서 정리하려고 한다. 완료한 일과 아직 남은 일을 함께 남기는 것이 이 블로그의 기준이다.
