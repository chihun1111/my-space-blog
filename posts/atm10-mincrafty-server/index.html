MinCrafty 안에 ATM10 모드팩 서버를 올려 봤다

Proxmox의 게임 VM과 MinCrafty 패널 안에 ATM10을 구성한 기록. VM 자원, 서버팩과 Java, 관리 화면과 게임 접속의 차이를 다룬다.

Chihun2026년 10월 22일수정 2026년 11월 26일6분 읽기

홈서버에 MinCrafty 관리 패널을 올리고, 그 안에서 ATM10 모드팩 서버도 구성해 봤다. 패널만 띄워 둔 것이 아니라 실제 마인크래프트 모드팩을 올리는 데 이 환경을 사용했다. 게임용 VM을 만들고 그 안에 관리 도구와 게임 서버를 함께 둔 구조다.

Proxmox 안의 VM, 그 안의 관리 패널과 모드팩

Proxmox가 관리하는 대상은 게임용 VM이다. MinCrafty는 그 VM 안의 서버 관리 환경이고, ATM10은 안에 올려서 사용한 모드팩이다. 세 이름이 같은 대상을 가리키지는 않는다.

Text
Proxmox 호스트
  └─ 게임 관리용 VM
       ├─ MinCrafty 웹 관리 패널
       └─ ATM10 모드팩 서버

VM의 CPU·메모리와 디스크 크기는 Proxmox 쪽 설정이다. 게임 서버의 실행 명령이나 Java 메모리는 그보다 안쪽의 설정이다. VM에 자원을 배정한 다음에도 모드팩 실행 환경은 따로 맞아야 한다.

2026년 10월 22일에 남아 있는 VM 설정은 4코어, 메모리 6144MiB, 시스템 디스크 80G다. 디스크는 local-lvm에 있고 네트워크는 vmbr0에 연결돼 있다. 이 값은 현재 보관 중인 VM의 구성으로, ATM10을 돌리던 모든 시점의 자원 설정을 나타내지는 않는다.

ATM10은 서버팩까지 맞춰야 하는 모드팩이다

올려 본 모드팩은 All the Mods 10, 줄여서 ATM10이다. 공식 배포는 Minecraft 1.21.1과 NeoForge를 기반으로 하며 서버용 파일도 별도로 제공한다. 일반 서버 실행 파일 하나와 모드팩 서버 전체를 같은 것으로 다룰 수 없는 이유다. ATMTeam의 공식 배포 페이지

ATM 공식 안내에서는 플레이할 팩 버전을 고른 뒤 그 버전의 Additional Files에서 Server Files를 받도록 설명한다. 클라이언트에 설치한 ATM10과 서버에 올리는 서버팩은 같은 팩 버전을 기준으로 확인해야 한다. 마인크래프트 버전만 같다고 팩 안의 모드 구성까지 같아지는 것은 아니다. 공식 서버 설치 안내

현재 공식 Java 안내에서 Minecraft 1.21 이상에 사용하는 버전은 Java 21이다. 여러 Java가 있는 환경에서는 기본 java와 서버 시작 스크립트가 호출하는 Java 경로도 구분해야 한다. 이 내용은 ATM10 실행 환경을 설명하는 기준이며, 당시 내 VM에 설치했던 정확한 Java 버전이나 경로의 기록은 남아 있지 않다. Java 버전과 실행 경로

관리 화면의 8443과 게임 접속은 다르다

MinCrafty를 실행했을 때는 8443/TCP에서 웹 요청에 응답했고 /panel/dashboard로 리다이렉트했다. 이 주소는 브라우저로 관리 패널에 들어가는 통로다. 마인크래프트 클라이언트가 ATM10 서버에 접속할 때 사용하는 포트와는 역할이 다르다. Crafty 공식 문서도 HTTPS 관리 포트와 게임 서버 포트를 따로 다룬다. Crafty의 접속과 포트 구분

바깥에서 보이는 대상맡는 역할
Proxmox의 VM가상 하드웨어와 전원 관리
MinCrafty의 8443 웹 패널브라우저에서 서버 관리
ATM10 게임 서버모드팩을 사용하는 게임 환경

패널이 열린다는 것만으로 모드팩 초기화나 게임 접속까지 확인되는 것은 아니다. 서버를 다시 구성할 때도 관리 화면 접속, 모드팩 실행, 게임 클라이언트 접속을 차례로 구분해 살펴야 한다. ATM10을 올린 위치는 같아도 각 단계에서 문제가 생기는 지점은 다르다.

현재는 모드팩을 올렸던 VM을 보관하고 있다

2026년 10월 22일에는 이 VM이 중지 상태였다. 현재 메모리 6GiB는 VM 전체의 할당량이며 Java의 최대 힙이나 ATM10의 권장 메모리로 읽으면 안 된다. 패널·운영체제·게임 프로세스가 같은 VM 안에 있으므로 VM 메모리와 게임 프로세스 메모리는 구분해서 봐야 한다.

당시 사용한 ATM10의 세부 팩 버전, 실행 옵션, 게임 포트는 별도 기록이 없어 특정 값으로 적지 않았다. 지금 남아 있는 것은 MinCrafty 안에 ATM10을 구성해 본 경험과 그 작업에 사용한 게임 VM이다.
