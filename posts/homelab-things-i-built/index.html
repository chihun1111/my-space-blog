내 홈서버 구축 기록

Proxmox VM 설정부터 TrueNAS, 원격 접속, 게임 서버까지 홈서버 글을 네 주제로 묶었다.

Chihun2026년 10월 22일6분 읽기

내 홈서버는 Proxmox 위에 저장소, 자동화, 게임 서버, 개발 환경을 나눠 둔 구성이다. VM을 만들고 서비스를 올리면서 해본 작업을 네 가지 주제로 묶었다. 각 글에는 실제 설정과 수정 과정을 따로 남겼다.

VM 설정은 Ubuntu 템플릿부터 보면 기본 구성이 드러난다. TrueNAS 구성에는 디스크와 공유, 백업을 연결한 방식이 담겨 있다.

서버 설정

홈서버 VM마다 CPU와 메모리를 다르게 둔 구성

VM 열 개의 자원 배정과 CPU 유형을 비교하고, q35·OVMF·SeaBIOS 설정을 구분했다.

Proxmox VM 디스크, local-lvm과 VirtIO SCSI 설정

시스템 디스크와 물리 데이터 디스크, 컨트롤러·discard·I/O 스레드·백업 제외 옵션을 다룬다.

VM 네트워크를 vmbr0에 연결하고 Cloud-Init 주소를 나눴다

공통 브리지와 VirtIO NIC, DHCP·고정 주소, Cloud-Init 매체의 연결 관계를 정리했다.

NAS부터 시작하도록 둔 VM 부팅 순서

자동 시작 여부와 시작 순서·대기 시간, VM 안의 부팅 장치, 게스트 에이전트의 응답을 구분했다.

새 VM의 바탕으로 남겨 둔 Ubuntu 템플릿

10G 시스템 디스크와 Cloud-Init 드라이브를 붙인 Ubuntu 24.04 템플릿이다. 개발·데이터 VM의 주소와 자원 설정도 비교했다.

NAS·서비스

Proxmox에 올린 TrueNAS, 실제 디스크와 공유 구성

로컬 부팅 디스크와 물리 데이터 디스크를 나누고, ZFS 풀·SMB 공유·VM 백업 저장소를 연결한 구성이다.

TrueNAS에 Nextcloud를 올리고 파일과 DB 저장 공간을 나눴다

파일 데이터는 nc_pool에, 앱과 데이터베이스는 앱 관리 볼륨에 연결했다. 백그라운드 작업과 상태 API 응답까지 다룬다.

TrueNAS에 Immich를 올린 구성, 사진 저장소와 머신러닝 서비스

사진 데이터는 tank에 두고 서버·데이터베이스·머신러닝 서비스를 함께 실행하는 구성이다.

TrueNAS에 Netdata를 붙여 서버 상태를 보는 환경 만들기

NAS 안의 모니터링 앱과 19999 포트, 저장 볼륨, 수집 옵션을 정리했다.

PostgreSQL과 데이터 처리 서비스를 한 VM에 모았다

PostgreSQL과 네 처리 서비스를 함께 둔 환경이다. Cloud-Init의 고정 주소 설정과 로컬 디스크 구성을 다룬다.

자동화·접속

n8n을 올려 쓴 전용 VM, 자원과 네트워크 설정

2코어·6GiB·60G VM에 고정 주소와 Cloud-Init, 자동 시작 순서를 둔 구성이다. VM 전원 상태와 앱에 접속할 수 있는 상태도 구분했다.

WOL 포털로 PC를 켜고 Windows·Ubuntu 부팅까지 연결하기

브로드캐스트 수정과 패킷 재전송부터 Windows 준비 대기, 일회성 Ubuntu 부팅, OS별 전원 명령을 고쳐 온 과정이다.

Tailscale과 SSH로 홈서버에 접속하기

개발용 VM으로 직접 접속하는 경로와 Proxmox 호스트를 거치는 경로, 접속 상태와 애플리케이션 상태의 차이를 다룬다.

Proxmox에 Home Assistant VM을 올려 봤다

2코어·4GiB VM에 Core, Supervisor, Matter와 원격 접속용 구성을 올렸다. SATA 부팅 디스크와 NAS 뒤에 시작하도록 둔 설정도 함께 정리했다.

온라인인 Discord 봇이 답하지 않던 이유

자체 Discord bridge의 메시지 수신·답변 전송·CLI 호출 오류를 고친 과정부터 공식 Hermes 설치와 이후 VM 상태까지 이어 썼다.

게임 서버

게임 관리 VM에 MinCrafty 패널을 올려 봤다

4코어·6GiB·80G VM에 웹 관리 패널을 올리고 8443 포트 응답과 대시보드 리다이렉트를 확인한 내용이다.

MinCrafty 안에 ATM10 모드팩 서버를 올려 봤다

패널 안에서 ATM10을 구성해 본 경험이다. VM·관리 패널·모드팩의 역할과 서버팩 버전, Java, 게임 접속을 구분했다.
