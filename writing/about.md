안녕하세요. 웹 서비스를 만들고 서버를 직접 다루는 개발자 **이치헌**입니다. GitHub에서는 **chihun1111**이라는 이름으로 작업합니다. 화면의 입력이 API와 데이터베이스를 거쳐 결과로 돌아오는 과정, 그리고 그 과정이 중단됐을 때 다시 이어지는 방법에 관심이 많습니다.

최근에는 HOP Biohealth AI Challenge의 팀 프로젝트 **말씨**에서 백엔드와 모델 연결, 대화 흐름을 개선했습니다. PostgreSQL과 Gemma 모델 경로를 연결하고, 요청이 실패해도 입력을 남겨 재시도할 수 있도록 다듬었습니다. 질문을 선택하는 모델과 최종 카드를 만드는 모델의 역할을 나누고, 답변 수정이나 서버 재시작 뒤에도 올바른 결과를 저장하도록 처리하는 작업에 기여했습니다.

**CTF 운영 플랫폼**은 참가자 화면과 관리자 기능을 직접 구현하고 서버 구축·배포까지 맡은 프로젝트입니다. 문제의 유형과 난이도를 구성하고, 참가자별 플래그와 제출 내역, 완료 여부를 관리하는 흐름을 만들었습니다. Next.js와 NestJS, PostgreSQL을 연결하면서 인증과 데이터 저장, Docker·Nginx 배포 설정을 함께 다뤘습니다.

개인 환경에서는 **Proxmox와 TrueNAS를 중심으로 홈서버**를 구성해 왔습니다. NAS, 개발 환경, 데이터 처리, 자동화, 게임 서버를 나누고 원격 접속과 전원 제어도 붙였습니다. 온라인으로 표시되지만 답하지 않는 Discord 봇을 고치거나, WOL 포털에서 패킷 전송과 OS 준비 확인을 나누는 일처럼 구체적인 문제를 다룹니다.
