웹에서 시작한 기능이 서버에서 끝까지 동작하는 과정에 관심이 많습니다. 화면과 API를 연결하고, 데이터를 저장하고, 배포한 뒤 생기는 문제를 따라가며 개발합니다. GitHub에서는 **chihun1111**이라는 이름으로 작업하고 있습니다.

최근에는 HOP Biohealth AI Challenge의 팀 프로젝트 **말씨**에 참여해 PostgreSQL과 Gemma 모델 경로를 연결하고 대화 흐름을 개선했습니다. 모델 호출이 실패해도 입력을 보존하고, 답변을 수정했을 때 오래된 결과가 덮어쓰지 않도록 다듬었습니다. 질문을 고르는 모델과 최종 카드를 만드는 모델의 역할을 나누고, 후속 대화·결과 저장·재시작 복구까지 이어지는 작업을 반영했습니다.

**CTF 대회를 위한 웹 플랫폼**은 직접 구현하며 서버 구축과 배포까지 맡았습니다. 문제의 유형과 난이도를 구성하고, 참가자의 진행 상황과 제출 내역을 관리하는 기능을 만들었습니다. 지금 공개한 코드에서는 인증과 권한, 개인별 플래그, 제출 처리와 감사 기록, 서비스 배포 경계를 함께 다루고 있습니다.

개발 환경 밖에서는 **Proxmox와 TrueNAS를 중심으로 홈서버**를 구성해 왔습니다. 저장소, 개발 환경, 자동화, 게임 서버를 VM과 서비스로 나누고, 원격 접속과 전원 제어도 직접 다뤘습니다. 이 블로그의 홈서버 글에는 2026년 10월에 확인한 구성과 그때 해결한 문제를 남겼습니다. 각 글에서 설정값과 실제 응답, 아직 확인하지 못한 부분을 구분합니다.

## 이곳에 남기는 것

- **개발 과정:** 어떤 문제를 해결하려고 만들었는지, 상태와 데이터의 경계를 어떻게 나눴는지.
- **서버 운영:** VM·스토리지·네트워크를 구성하고 서비스에 연결한 과정.
- **문제 해결:** 실패한 시도, 원인을 좁힌 과정, 바꾼 코드와 확인한 결과.
- **프로젝트 회고:** 팀 안에서 맡은 작업, 완성한 기능, 다음에 더 검증할 부분.

완성된 결과만 올리기보다, 다시 같은 문제를 만났을 때 이어서 작업할 수 있는 기록을 쌓으려고 합니다.
